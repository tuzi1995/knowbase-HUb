## 部署链路核实（用户问"发布走的是什么"）
- **本地 8085**：`重启应用.sh` → `run_server.sh` → Flask `server.py`，静态目录 `KMATRIX_STATIC_DIR=link_viewer`，根路由 `send_from_directory(_STATIC_DIR, 'index.html')` → **直接 serve 未压缩 dev 版 index.html**
- **云端部署**：`🚀 启动脚本/package_deploy.py` 打 zip，整包包含 `link_viewer/`（仅排除 dist/、node_modules、backup、.pyc），云上运行同一份 server.py → **同样 serve index.html（未压缩版）**
- **结论**：`link_viewer/deploy.sh`（npm build → dist → 生成 index.prod.html/min 文件）是历史优化流程，当前实际部署（本地+云端）入口均为未压缩 `index.html`；min/prod 文件会被打包上去但不是入口页。改 dev 文件即可，无需构建 min
- server.py 关键行：167-168（静态目录解析）、272（Flask static_folder）、1692（根路由返回 index.html）
