### 本项目 CSS 重要坑（后续改 UI 必看）

- `extra_styles.css` ~8294 行的 kb-workbench 全局段：`table th { background:#dceeff !important }`、`table td { background-color:... !important }`，会强暴覆盖所有表格样式。定制表格表头需 `!important` 反击，行 hover/is-multi 等背景必须写到 **td 级**（tr 背景会被 td 盖住）。
- `styles.css` 的 `th` 有 `background: linear-gradient(...)` 和 `height:48px`。
- `.primary-btn/.action-btn/.success-btn` 全局是大按钮（min-height 40px/radius 14px，颜色在 design-system.css），弹窗工具栏内要用作用域选择器收敛（参考 `.mm-toolbar .xxx` 写法）。
- Chrome 原生 CSS Nesting 使无嵌套规则的 `rule.cssRules` 是空列表但 truthy，遍历诊断脚本会误判跳过，要先看 `rule.selectorText`。
