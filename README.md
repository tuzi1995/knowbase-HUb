# KnowBase Hub（8085）

KnowBase Hub / K-Matrix 本地知识库工作台项目，包含主应用、配置、启动脚本以及独立的 QA（质量验证）桥接入口。

## 启动入口

- 主应用启动脚本：[`🚀 启动脚本/start.sh`](🚀%20启动脚本/start.sh)
- QA 桥接启动：`启动18787-qa桥接.command`
- 主应用目录：`KnowledgeBaseTool_Local/`
- 部署说明：[`🚀 启动脚本/README_DEPLOY.txt`](🚀%20启动脚本/README_DEPLOY.txt)

启动前确认所选实例、配置文件和端口。主应用与 QA 桥接是不同入口，不要混用配置。访问地址以启动脚本输出为准。
